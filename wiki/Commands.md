# Commands

Evoker's Omen items can be obtained directly with `/give` when cheats or command permissions are available.

```mcfunction
/give @s evokers-omen:evokers_omen_1
/give @s evokers-omen:evokers_omen_2
/give @s evokers-omen:evokers_omen_3
/give @s evokers-omen:evokers_omen_4
/give @s evokers-omen:evokers_omen_5
```

These commands are useful for testing, Creative worlds, and modpack development.

## Namespace

The mod ID and command namespace are:

```text
evokers-omen
```
