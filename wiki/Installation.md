# Installation

## Requirements

Evoker's Omen 1.0.0 requires:

- Minecraft 26.2
- Fabric Loader 0.19.3 or newer
- Fabric API 0.160.0+26.2
- Java 25 or newer

## Installing the mod

1. Install Fabric Loader for Minecraft 26.2.
2. Install Fabric API.
3. Place `evokers-omen-1.0.0.jar` in your Minecraft `mods` folder.
4. Place the matching Fabric API JAR in the same `mods` folder.
5. Launch Minecraft using the Fabric profile.

Do not use the `-sources.jar` file as the playable mod.

## Singleplayer and multiplayer

Evoker's Omen's gameplay logic is server-side and also works in singleplayer through Minecraft's integrated server.

For a dedicated multiplayer server, install Evoker's Omen and Fabric API on the server. Dedicated-server compatibility should be treated as unverified until it has been specifically tested.
