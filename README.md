# Evoker's Omen

Evoker's Omen is a Fabric mod for Minecraft 26.2 that adds a five-level brewing progression for triggering increasingly difficult Evoker-only raids.

Vanilla Ominous Bottles and vanilla raids remain unchanged. Normal mob spawning and `/summon` behavior are also unaffected.

## Features

- Five levels of Evoker's Omen
- Custom brewing progression
- Evoker-only raids
- Increasing Evoker counts at higher Omen levels
- Scaling Emerald rewards
- Evoker's Omen item drops
- Vanilla raids remain completely unchanged
- Custom textures for all five Omen levels

## Requirements

- Minecraft 26.2
- Fabric Loader 0.19.3 or newer
- Fabric API
- Java 25

## Building

Build the project with JDK 25 and Gradle/Loom:

`./gradlew build`
